# Take-Home Pay Calculator

I'm building a one-page website to help people estimate how much of their salary they take home after Income Tax, National Insurance and other deductions. It will make the difference between a salary before deductions and the amount available to spend easier to understand.

The calculator will initially support UK salaries. Later, I plan to add other countries, with their own tax rules and currencies.

This is a personal learning project to develop my web development skills and gradually introduce testing, containerisation, cloud deployment and automated pipelines.

## Technologies

### Initial development

The initial website will use vanilla HTML, CSS and JavaScript, without additional frameworks or dependencies.

- **HTML5:** structures the page and its content.
- **CSS3:** controls appearance and adapts the layout to different screen sizes.
- **JavaScript:** handles calculations and user interactions.
- **Git and GitHub:** track changes and document development.

### Planned for later

These tools and practices have not yet been implemented:

- **Docker:** packages the application so it runs consistently in different environments.
- **GitHub Actions:** automatically runs tests and code checks when changes are made.
- **Cloud hosting:** makes the website accessible online; the provider is still to be decided.
- **CI/CD:** automates testing and deployment of new changes.
- **Automated testing tools:** check that the application works as expected; tools will be selected during development.
